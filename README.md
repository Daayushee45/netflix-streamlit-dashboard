# 🎬 Netflix Streamlit Dashboard

An interactive dashboard built using **Streamlit** to analyze Netflix content trends, genres, ratings, and country distribution.

---

## 🚀 Features

* Interactive filters (Type, Country, Year)
* KPI metrics (Total Titles, Movies, TV Shows, Countries)
* Genre and Ratings analysis
* Country-wise content distribution
* Content growth over time

---

## 🛠️ Tech Stack

* Python
* Streamlit
* Pandas
* Plotly
